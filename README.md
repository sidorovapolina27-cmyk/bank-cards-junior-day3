# Этап 03: MapStruct: переход с ручного маппера

Учебный проект команды отображения карт банка.
Полное описание заданий этапа — в файле **03-zadanie.pdf** в этой папке.

## Подготовка

1. База данных: создайте базу `cards_stage03` в локальном PostgreSQL (пользователь `dev`):

   ```sql
   CREATE DATABASE cards_stage03;
   ```

   Схему и тестовые данные создаёт Liquibase при первом запуске.

2. Перед каждым заданием делайте копию папки проекта (или `git init` и коммитьте после каждого задания).

## Проверка себя

```bash
mvn test
```

Тесты текущего задания в начале этапа падают — это нормально.
К концу этапа **все** тесты проекта должны быть зелёными.

## Запуск приложения

```bash
mvn spring-boot:run
```

Порт 8080. Пример запроса: `curl http://localhost:8080/api/cards/2001`
